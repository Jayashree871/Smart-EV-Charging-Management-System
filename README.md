A web-based application that allows EV users to view charging stations, check availability, and book charging slots online.
**Objective:** To develop a web-based system for managing EV charging station bookings and charging activities.
**Features:**
1.User Registration
2.User Login
3.View Charging Stations
4.Check Available Slots
5.Slot Booking
6.Booking History
**Technology Stack**
1.HTML
2.CSS
3.JavaScript
4.MySQL
